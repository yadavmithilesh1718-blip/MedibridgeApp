Web & Mobile Dual Ecosystem

How MediBridge operates across Web and Android like Amazon & Flipkart

🌐 1. Web Application

  • Runs in any browser (Chrome, Safari, Edge, Firefox).
  • Optimized for desktop computers, hospital workstations & tablets.
  • PWA support: Can be installed as a standalone app with 1 click.
  • Zero download required for donors & clinic staff.

📱 2. Native Mobile App

  • Built with Kotlin & Jetpack Compose.
  • Native camera hardware integration for instant AI OCR packaging scan.
  • Push notifications for urgent clinic match requests.
  • Offline Room SQLite database persistence.
🚀 How to Deploy Web Version to Cloud (Vercel / Firebase / Netlify)

The files in app/src/main/assets/web/ are 100% standard HTML5/CSS/JS. Deploy them with one command:

# Option 1: Test locally in terminal
npx serve app/src/main/assets/web

# Option 2: Deploy to Vercel
npx vercel app/src/main/assets/web

# Option 3: Deploy to Firebase Hosting
firebase deploy --only hosting
